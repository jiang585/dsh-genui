# 架构与开发说明

[返回 README](../README.md)

## 代码分层

| 路径 | 职责 |
|---|---|
| `lib/host.js` | `/genui/*` 资源、编译与状态接口；复用 DSH connection 认证 |
| `lib/client.js` | 客户端 module-loader bundle、genui_render 卡片、流式参数、高度与外层展开样式 |
| `lib/compile.js`、`compile-worker.cjs` | 独立 Node 线程编译，处理并发、大小与超时 |
| `lib/state-store.js` | 调用归属、会话状态、TTL、快照持久化与提示词投影 |
| `plugins/genui-tools-v2.js` | 当前界面生成工具与模式/状态提示词 |
| `plugins/genui-readonly.js` | 按 agent 屏蔽 write/edit，并在执行入口拒绝变更 |
| `vendor/frame-page.html` | 可信同源宿主页：编译请求、渲染器、消息桥和内容测量 |
| `vendor/compiler/` | DIL 解析、修复、验证、代码生成 |
| `vendor/sandbox/` | 不透明 origin runner 与 Worker 执行/恢复逻辑 |
| `vendor/public/dil/` | 可信 DOM 渲染、事件函数 ID、状态上报和程序版本管理 |
| `cordis.patch.yml` | profile 插件与 genui preset 装配，使用包导出子路径引用 |

历史入口/变体与本机验证脚本也保留在仓库中。当前发布入口以 package.json 的 main/exports 和 cordis.patch.yml 为准，不要将本地 live2 名称或 E 盘路径照搬为安装要求。

## 数据和权限边界

外层 frame 是可信页面，可以请求同源编译/状态接口。内层 runner 为 `sandbox="allow-scripts"`，不开放 allow-same-origin；CSP 的 default-src 为 none，Worker 通过 blob（或 data 备用通路）启动。

模型程序输出元素树；渲染器选择固定组件并更新 DOM。事件通过 `__dilFn` ID 与值传回 Worker，不把模型函数放到应用文档执行。独立编译线程和 Worker 预算是资源控制手段，不能把异常降级函数当作安全隔离。

## 接口

所有资源与接口复用 DSH 浏览器认证，POST 要求 application/json。

| 方法与路径 | 请求 / 响应 |
|---|---|
| GET `/genui/frame.html` | 卡片宿主页 |
| GET `/genui/runner.html` | CSP 受限 runner |
| GET `/genui/dil/*` | 本地浏览器运行时资源，路径限于指定目录 |
| POST `/genui/compile` | `{source}` → 编译代码、常量、组件信息与诊断 |
| POST `/genui/view_state` | `{call_id, updates:[{scope:'root',state,reason}]}` → 状态写入确认 |
| GET `/genui/state?call_id=...` | 已保存的结构化状态；未绑定调用返回409 |

会话归属由工具执行上下文建立，前端不能用 session_id 自行指定归属。诊断数据不进入用户状态。

## 状态与生命周期

DIL 的 `useState` 声明由编译器处理为可上报的语义键。控件变更在本地重新渲染，经节流和串行请求保存；下一轮提示词按当前会话读取状态，并将其标为不可信数据。

快照默认位于 `%LOCALAPPDATA%/DSH/<插件目录名>-state-v2.json`；没有 LOCALAPPDATA 时使用用户主目录。`GENUI_STATE_FILE` 可覆盖路径。变化后约100ms去抖落盘；写盘失败时只剩进程内状态。重新挂载卡片时按callId获取初始状态。

宿主 ESM 模块按 URL 缓存。更新插件后重启 DSH，再在新会话中验证装配；仅刷新前端不等于后端已重新加载。既有会话可能仍持有旧模式版本。

## 默认预算

| 环节 | 限额 |
|---|---|
| DIL 源码 | 128 KiB |
| 编译线程 | 并发2个、每任务2秒、堆上限64 MB |
| HTTP 请求体 | 256 KiB |
| 单次 root 状态 | 8 KiB、最多100个键 |
| 提示词状态 | 最多4000字符 |
| 状态保留 | 7天、最多256个调用 |
| Worker 渲染 | 2500ms，最多重生1次；最终隔离会终止线程 |
| 流式编译合并 | 60ms，同时只应用最新有效结果 |
| 状态上报 | 400ms，串行发送 |
| 卡片高度 | 最小120px，按内容测量增长/收缩 |

## 验证层次

1. `regression.mjs`、`readonly-test.mjs`：逻辑和装配契约；部分宿主组件使用替身。
2. `browser-regression.mjs`、`outer-scroll-regression.mjs`：真实浏览器、编译、iframe、Worker、DOM及交互；外层测试读取本机DSH源码中的工具组CSS。
3. `verify-real-sessions.mjs`：本机独立DSH进程与真实模型请求，记录工具表、读取内容、调用与持久化日志。

各层的通过不能替代其他层。现有真实会话证据主要使用本地live2副本；浏览器截图不应描述成用户GUI截图。运行本机脚本前检查其路径和配置；不建议在他人的机器上直接执行 profile 修复或复制脚本。

## 生成文档截图

```sh
node tools/capture-readme-screenshots.mjs
```

要求 Node ≥22、Microsoft Edge 或支持 CDP 的 Chromium 浏览器。Windows 默认路径是 `C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`；其他位置可用环境变量指定：

```powershell
$env:EDGE_BIN = 'C:/path/to/chrome.exe'
node tools/capture-readme-screenshots.mjs
```

脚本加载模型实际生成的 `tools/real-sales-interface.dil`，创建独立临时 profile 和本地测试服务，核对 CSV 汇总数字后截取浅色、深色与季度切换画面。输出 `docs/images/dashboard-light.png`、`dashboard-dark.png`、`quarterly-detail.png`。浅/深色图为界面局部，季度图为完整内容。

不会发起新模型请求或操作用户GUI。测试服务的Cookie准入只用于隔离夹具，生产宿主使用DSH connection认证。脚本保留临时目录，便于失败时排查。
