# 参考资料

这份清单列出「智能界面模式」插件（`dsh-genui`）用到的每一处外部参考：**链接 + 它提供了什么 + 在本仓库里对应什么**。想追溯某个设计决定或某段 vendored 代码的来源时，从这里开始。

---

## 1. 灵感来源（X / Twitter）

- 链接：<https://x.com/rabi_guha/status/2108238432355123572>
- 提供了什么：最初的思路触发点 —— 「模型不只是写文字，而是直接写出一件可以操作的界面」这件事的公开讨论。
- 在本仓库里对应什么：本项目要回答的问题本身，也就是「能不能用 DSH 插件复刻这件事，并把它做成一个模式」。

## 2. 实现拆解博客

- 链接：<https://blog.pdjjq.org/post/detailed-explanation-of-intelligent-ui-implementation-4rp54>
- 提供了什么：对「模型直接写界面」这套协议实现的逐条拆解 —— 方言怎么被编译、界面代码在什么边界里执行、界面状态怎么回到下一轮对话。
- 在本仓库里对应什么：`vendor/compiler/**`（DIL 编译器）、`vendor/sandbox/**`（runner 文档与 Worker）、`vendor/public/dil/**`（浏览器运行时与状态上报）的设计依据。

## 3. 复刻参考仓库（代码来源）

- 链接：<https://github.com/Disdjj/intelligent-ui-demo>
- 提供了什么：一份可运行的公开复刻实现 —— 流式 DSL 编译器、iframe + Worker 沙箱、宿主渲染器、状态回环，以及配套的抓包分析笔记（`ANALYSIS.md`、`RUNNER-SANDBOX.md`、`ARTICLE.md`、`BLOG.zh-CN.md`）与 `replica/` 目录。
- 许可：MIT，`Copyright (c) 2026 DJJ`；许可原文保存在本仓库 [`vendor/LICENSE-intelligent-ui-demo`](../vendor/LICENSE-intelligent-ui-demo)。
- 本仓库怎么用它：`vendor/` 是这份实现的**本地 vendored 副本**（不是运行时依赖，不联网拉取），并按本插件的需要做了局部改动。**逐目录的来源与改动对照见 [`vendor/THIRD-PARTY.md`](../vendor/THIRD-PARTY.md)**，要点是：
  - `vendor/compiler/**` ← `replica/server/compiler/**`：改为 CommonJS 打包形态、收敛导出；DIL 文法与代码生成逻辑未改写。
  - `vendor/sandbox/frame.js` ← `replica/server/sandbox/frame.js`：资源路径改写到本插件挂载前缀；CSP 与 opaque origin 策略保持。
  - `vendor/sandbox/worker.js` ← `replica/sandbox/worker.js`：保留 Worker 侧执行与元素树回传协议。
  - `vendor/public/dil/**` ← `replica/public/dil/**`：资源路径改写；`dil.css` 做了主题/深色模式/焦点态与排版调整；`view-state.js`、`message-view.js` 增加编译版本防乱序与状态串行上报。
  - `vendor/agent/system-prompt.js`：由上游产出的方言说明整理成模型可读的 DIL 方言规范。
- 上游声明（值得一并知道）：该项目是出于学习目的的独立研究，**与 OpenAI 无关、也未获其认可**；其中的抓包数据已脱敏，且不包含 OpenAI 的运行时代码。

## 4. 宿主平台

- 链接：[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（本仓库不附带宿主源码；插件通过 DSH 的插件与 preset 机制接入）
- 提供了什么：插件行与 agent preset 的装配（`cordis.patch.yml`）、工具注册与按 agent 的 `tools.restrict()` / `tools.guard()`、系统提示词分段、`webServer` 前缀路由与 `ctx.connection.requestRejection` 浏览器认证、出厂文件工具与 `ctx.fs`（工作目录、路径授权、读取上限、附件与模型能力检查）、长对话压缩栈。
- 在本仓库里对应什么：`cordis.patch.yml`（模式与工具面装配）、`lib/host.js`（路由）、`lib/client.js`（工具卡片槽位 `tool.call.toolview`）、`plugins/genui-tools-v2.js`（`genui_render` + 两段提示词）、`plugins/genui-readonly.js`（只读掩码）。
- 版本要求：`package.json` 的 `dsh.engines.dsh` 为 `>= 0.1.7-rc.2`，`engines.node` 为 `>= 20`。

## 5. 社区
